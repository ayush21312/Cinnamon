# Supplied font assets

The user supplied `Anthropic Serif-fontiko.zip`. It contains Anthropic **Serif**, not Sans. These seven styles were extracted from that archive and are self-hosted; no third-party font requests are made at runtime. The interface uses the Text family throughout, with Display Bold Italic for the Cinnamon title.

No license document was included in the supplied archive. Preserve the font owner's license terms for any public redistribution. This folder records provenance and does not grant additional rights to the fonts.
